# M4 Pro 缓存覆盖与统一内存带宽核对

核对日期：2026-10-13。Mac16,8；M4 Pro；14 核 CPU（10P+4E）、20 核 GPU、48 GiB 统一内存。使用本轮已保存数据，未重新跑整套测试，也未修改成绩。

**判断：约 239–246 GB/s 的大工作集读取速度与这台 M4 Pro 的规格相符，当前证据没有显示明显带宽异常。** Apple 官方标称带宽为 **273 GB/s**。[Apple 14 英寸 M4 Pro 规格](https://support.apple.com/en-au/121553)

| 测量 | 读取 GB/s | 标称峰值占比 | 证据 |
|---|---:|---:|---|
| Vulkan | 238.796 | 87.5% | 2 GiB 扫描；最大三档已平稳；GPU timestamp；异常计时 0 |
| Metal | 244.776 | 89.7% | 512 MiB 原生预览；取最好值；未验证内存平台 |
| CPU | 245.834 | 90.0% | 14 线程；最大工作集合计约 3.5 GiB；内存平台已平稳 |

Vulkan 最后三个数据集（1、1.5、2 GiB）分别约 236.9、238.8、240.0 GB/s；它们的中位数就是约 238.8 GB/s。CPU 全核末端也稳定在约 243–247 GB/s。两种独立访问路径一致，是判断大工作集已进入 DRAM 区域的依据。273 GB/s 为官方规格值，软件内核持续有效吞吐不必达到它。两项都按十进制 GB/s 计算，未将 GiB/s 混入峰值比较。

Apple 官方说明 GPU 的 ALU/纹理单元有专用 L1，GPU 核心之间还共享末级缓存。当前曲线与现有结果字段不足以把它们机械映射成通用 L1/L2/L3 三层，也不足以把 SoC/SLC 单独标定。[Apple GPU 缓存架构说明](https://developer.apple.com/videos/play/wwdc2020/10603/)

CPU 系统信息还显示：P 核 L1D 128 KiB、每 5 个 P 核共享 16 MiB L2；E 核 L1D 64 KiB、4 个 E 核共享 4 MiB L2。当前单线程测试没有核绑定，因而不能声称已分别测出 P 核和 E 核各自的速度。系统未提供可用的 SoC/SLC 容量字段给当前测试。

## 为什么 GUI 没有列出 L1/L2/L3

GPU 页面目前只把 MEMBW_POINT 曲线画出来，尚未解析/列出 MEMBW_L1 和 MEMBW_SUMMARY 的缓存汇总表。历史页面也只显示主分数；上述缓存数据实际存于 results.json 的 workloadConfig。CPU 测试的 L1/L2 表属于 CPU 内存测试输出，不是 GPU 的 L1/L2。

所以前面的 31 项通过仅表示已实现的 31 个流程全部通过，不能解释为 GPU L1/L2/L3 与 SoC 缓存均已完成测试。未独立测出的层级必须保留为“未归因 / 未测定”，不能补一个推测数字。
