# 11 英寸 A12X iPad 一键实测（2026-10-16）

**后续七项已复核通过：**Vulkan 全程同步计时与 CPU 全核参与验证已改进，当前
完整选用 31 项均无复核警告。未重新点击整套，以下保留首轮记录。
详见 [后续设计核查与实测](ipad81-design-review-20261016.md)。

设备为 iPad Pro 11 英寸第一代，型号 iPad8,1，iPadOS 26.7.1。
它和 10 月 14 日测试的 12.9 英寸 iPad8,7 是两台不同的 A12X 设备。

## 实际按钮流程

通过真机 XCTest 找到首页 `complete-suite-all` 按钮并实际点击，没有使用自动开始
全套或定向任务的启动参数。既有转译 API 开关已启用。按钮文本实际为
“一键测试全部项目”，随后完整执行设备支持的 31 项并保存 33 条成绩。

首轮 22 项 passed、9 项 review，没有执行失败。严格 XCTest 要求最终状态为
passed，因此用例因 review 未通过，不能称为完整质量验收通过。测试结束后
Xcode 的日志收尾卡住，已终止该宿主；xcresult 未封装完整，截图导出不可用。
原生清单、每项日志、全部设备成绩均已在此之前独立归档，实际点击日志也保留。

## Auto 语言修复

iOS 原先使用 Locale.current 的语言代码推断 Auto；现在与 macOS 一样使用系统
首选语言列表，并在安装包声明英文、简体中文和日文。启动时先恢复已保存的语言
选择，再生成初始状态文字；“Auto”也按当前语言显示。

没有强制传入中文启动参数。界面自动化实际读到中文按钮；后续运行日志确认
`setting=auto preferred=zh-Hans-AU locale=zh-Hans_AU effective=zh`。

## Vulkan 纯计算计时修复及复测

1M／4M 纯计算在启动多次 dispatch 校准通过后，正式帧查询仍少算：平均 GPU
时间为 0.067／0.343 ms，实际帧间隔为 1.539／5.842 ms，报出约 625／489 GB/s。
这两条只保留为可疑查询计时观察，不能当作可信性能成绩。

iOS MoltenVK 纯计算现整轮使用提交／栅栏完成的同步耗时。前端不再将旧查询计时
复用为当前纯计算的通过记录；原始数据保留。Android／HarmonyOS 原生 Vulkan 和
macOS 桌面选择路径未变。相关合同检查、Release 引擎及签名 App 构建通过。

安装修正版本后补测三档，均 passed，热状态均为 0→0：

| 规格 | 成绩 | 同步计算 / 实际帧间隔 | 稳定段 |
| --- | ---: | ---: | ---: |
| 1M | 18.481 GB/s | 2.270 / 2.283 ms | 18.206 GB/s |
| 4M | 26.642 GB/s | 6.297 / 6.313 ms | 26.632 GB/s |
| 16M | 28.754 GB/s | 23.339 / 23.359 ms | 28.757 GB/s |

当前 31 项／33 条选用结果由首轮按钮流程加三项真实补测组成，生产模型匹配通过，
为 24 项 passed、7 项 review。**修正后没有重新点击完整 31 项流程。**
其他 Apple 设备的历史仍按各自保存的计时口径解释；旧查询计时不能直接充当新版
同步合同的验收记录，不表示所有旧成绩均错误。

| 项目 | 成绩 | 条件 |

| CPU 大核 | 110.384 MWork/s | 单线程类型驻留验证通过 |

| CPU 全核 | 655.509 MWork/s | 8 线程共同实际时间计分；完整三轮类型验证为 review |
| CPU 全核内存读取 | 51.790 GB/s | 大小核缓存／内存曲线、页面首次访问与文件存储已测 |
| Vulkan GPU 内存读取 | 58.051 GB/s | 新版写入／复制校验，整轮同步计时 |

全核第二轮部分 P 线程的类型驻留低于 99%，最低 98.372%；选中轮的各线程贡献
相加等于保存总分。不能用选中轮通过替代完整三轮的验证。小核缓存／内存仍为
后台策略，不作为正常频率小核峰值。

剩余 7 个 review：Metal 1M／4M／16M 绘制、Vulkan 1M／4M／16M 绘制，以及
CPU 全核驻留。其中 Metal 4M 还提示运行中吞吐下降超过 5%；其余 GPU 项目未找到
稳定段。没有继续重复测试挑分，也没有把热状态正常等同于频率恒定。
GPU 缓存曲线继续标为未归属，独立 L2／L3／SoC-SLC 归属不纳入本轮范围。
